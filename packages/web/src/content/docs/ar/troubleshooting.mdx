description: حلول للمشاكل الشائعة في تشغيل OpenCode، مشاكل مفاتيح API، مشاكل المحاكي الطرفي والترميز.
---

يقدم هذا الدليل حلولاً للمشاكل الأكثر شيوعاً التي قد تواجهها أثناء تثبيت وتشغيل OpenCode.

---

## 1. أخطاء مصادقة مفاتيح API (Authentication Errors)

* **الأعراض:** ظهور رسائل مثل `401 Unauthorized` أو `Invalid API Key`.
* **الحل:**
  1. تأكد من صحة المفتاح وعدم وجود مسافات إضافية في بدايته أو نهايته.
  2. افتح الواجهة التفاعلية واكتب `/connect` لإعادة إدخال المفتاح يدوياً.
  3. تأكد من أن حسابك لدى المزود (مثل Anthropic أو OpenAI) يحتوي على رصيد نشط أو بطاقة دفع مفعّلة.

---

## 2. مشاكل محاذاة النص والخطوط في الطرفية (Terminal Display Issues)

* **الأعراض:** ظهور أحرف غريبة أو عدم انتظام محاذاة الخطوط والأيقونات.
* **الحل:**
  * استخدم خطاً يدعم رموز **Nerd Fonts** (مثل JetBrainsMono Nerd Font أو FiraCode Nerd Font).
  * في نظام Windows، استخدم **Windows Terminal** مع بيئة **WSL2** بدلاً من Command Prompt التقليدي القديم.
  * تأكد من أن الطرفية مضبوطة على ترميز `UTF-8`.

---

## 3. خطأ تجاوز مهلة أوامر الطرفية (Command Timeout)

* **الأعراض:** إيقاف الوكيل عند تشغيل أمر تثبيت حزم أو بناء يستغرق وقتاً طويلاً.
* **الحل:**
  * يمكنك زيادة المهلة الافتراضية لتنفيذ الأوامر في ملف `opencode.json`:
  ```json
  {
    "timeout": 120000
  }
  ```

---

## 4. الحصول على سجلات تفصيلية للتشخيص (Debug Logs)

إذا واجهت سلوكاً غير متوقع أو خطأ في الـ TUI، شغّل OpenCode مع علم السجلات المفصلة:

```bash
opencode --verbose
```

سيتم عرض تفاصيل استدعاءات الـ API، والأدوات، والأخطاء البرمجية للمساعدة في تحديد المشكلة بدقة.

---

تتيح واجهة سطر الأوامر (**CLI**) في OpenCode استخدام قدرات الوكيل مباشرة من سطر الأوامر، سواء في الوضع التفاعلي (TUI) أو الوضع غير التفاعلي (Non-interactive) للتشغيل ضمن سكربتات الأتمتة وخطوط البناء المستمر (CI/CD).

---

## صيغة الأمر الأساسية

```bash
opencode [أمر / خيارات] [موجه_المهمة]
```

إذا تم تشغيل `opencode` بدون أي معاملات، فسيتم فتح واجهة الطرفية التفاعلية (**TUI**) في المجلد الحالي.

---

## الأوامر الشائعة

### 1. تنفيذ مهمة مباشرة (One-shot Execution)
لتشغيل مهمة سريعة دون الدخول في الواجهة التفاعلية، مرر النص مباشرة مع العلم `-p` أو `--prompt`:

```bash
# تشغيل مهمة مباشرة
opencode -p "افحص مشروع الاختبارات في tests/ واكتب تقريراً بالأخطاء المكتشفة"
```

### 2. تحديد نموذج أو مزود معين
يمكنك تجاوز النموذج الافتراضي المحدد في الإعدادات باستخدام العلم `-m` أو `--model`:

```bash
opencode -m anthropic/claude-3-5-sonnet-20241022
```

### 3. تحديد وضع الوكيل (Agent Mode)
اختر بين وضع البناء (`build`) أو وضع التخطيط (`plan`):

```bash
# تشغيل في وضع التخطيط فقط للقراءة والاستكشاف
opencode --agent plan -p "اشرح لي الهيكل المعماري لنظام المصادقة في هذا المستودع"
```

---

## قائمة الأعلام والخيارات (Flags)

| العلم (Flag) | الاسم الكامل | الوصف |
| :--- | :--- | :--- |
| `-p` | `--prompt <text>` | تشغيل موجه محدد مباشرة والخروج فور الانتهاء |
| `-m` | `--model <name>` | تحديد نموذج الذكاء الاصطناعي لهذه الجلسة |
| `-a` | `--agent <name>` | تحديد الوكيل المراد تشغيله (`build` أو `plan`) |
| `-c` | `--config <path>` | استخدام ملف إعدادات `opencode.json` مخصص |
| `-v` | `--version` | عرض رقم الإصدار المثبت من OpenCode |
| `-h` | `--help` | عرض قائمة المساعدة والخيارات المتوفرة |
| `--verbose` | `--verbose` | تشغيل تسجيل السجلات المفصل (Debug Logs) لأغراض التشخيص |

---

## التشغيل في بيئات CI/CD والسكربتات

عند دمج OpenCode في خطوط الأتمتة (مثل GitHub Actions أو GitLab CI)، يمكنك تفعيل الوضع الصامت وتمرير مخرجات الأوامر إلى ملفات خارجية:

```bash
opencode -p "راجع التغييرات في فرع git الحالي وتأكد من الالتزام بتنسيق prettier" > review.txt
```

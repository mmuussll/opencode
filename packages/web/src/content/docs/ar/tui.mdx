توفر واجهة الطرفية التفاعلية (**Terminal User Interface - TUI**) في OpenCode بيئة عمل غنية وسريعة تدمج قدرات الوكيل الذكي مباشرة داخل سير عمل المطور.

---

## اختصارات لوحة المفاتيح الأساسية

| الاختصار | الوظيفة |
| :--- | :--- |
| `Tab` | التبديل الفوري بين **وكيل البناء (Build)** و**وكيل التخطيط (Plan)** |
| `Ctrl + C` | إيقاف توليد النص الحالي أو إلغاء تنفيذ الأمر الجاري |
| `Ctrl + L` | مسح شاشة الطرفية الحالية |
| `Ctrl + P` | فتح لوحة الأوامر واختيار النماذج والمزودات |
| `Esc` | الخروج من القوائم المنبثقة أو العودة إلى حقل الإدخال الرئيسي |
| `↑` / `↓` | استرجاع سجل الأوامر والرسائل السابقة |

---

## الأوامر المائلة (Slash Commands)

يمكنك كتابة شرطة مائلة `/` داخل حقل الإدخال للوصول إلى الأوامر المدمجة السريعة:

### 1. إدارة الاتصال والنماذج
* `/connect` - فتح معالج ربط مزودات الذكاء الاصطناعي وإدخال مفاتيح API.
* `/model` - التبديل بين النماذج المتاحة لمشروعك (مثل التبديل من Claude 3.5 Sonnet إلى DeepSeek V3).

### 2. إدارة الجلسة والسياق
* `/clear` - مسح سياق المحادثة وبدء جلسة نظيفة جديدة مع الحفاظ على إعدادات المشروع.
* `/compact` - ضغط سياق المحادثة لتوفير استهلاك الـ Tokens عند العمل على مهام طويلة.
* `/history` - عرض الجلسات والمحادثات السابقة واسترجاع إحداها.

### 3. إعدادات المشروع والتهيئة
* `/init` - فحص مستودع المشروع تلقائياً وإنشاء ملف القواعد `AGENTS.md` وإعدادات `opencode.json`.
* `/help` - عرض قائمة المساعدة وشرح جميع الأوامر المتاحة.

## الإشارة إلى الملفات والرموز البرمجية (`@`)

يتيح لك OpenCode تضمين سياق محدد بدقة داخل رسالتك باستخدام الرمز `@`:

* `@filename`: كتابة `@` متبوعة باسم الملف يعرض قائمة إكمال تلقائي لاختيار أي ملف في مشروعك وتضمينه في السياق.
* `@dir/`: تضمين هيكل مجلد معين بالكامل.
* `@symbol`: تضمين دوال أو فئات (Classes) محددة.

```text
مثال:
راجع الدالة في @src/auth/jwt.ts واقترح طريقة للتعامل مع انتهاء صلاحية التوكن.
```

import { Tabs, TabItem } from '@astrojs/starlight/components';

يدعم OpenCode الاتصال بعشرات المزودين للنماذج الذكية، سواء عبر الخدمات السحابية الرسمية أو النماذج المفتوحة المشغلة محلياً.

---

## الربط التفاعلي السريع

أسهل طريقة لربط أي مزود هي فتح واجهة الـ TUI وكتابة الأمر:

```text
/connect
```

سيظهر لك معالج لاختيار المزود وإدخال مفتاح الـ API وتخزينه بأمان في جهازك.

---

## تهيئة المزودات عبر متغيرات البيئة (Environment Variables)

يمكنك أيضاً ضبط مفاتيح API في ملف `.env` في جذر مشروعك أو في متغيرات بيئة نظامك:

<Tabs>
  <TabItem label="Anthropic">
  ```bash
  export ANTHROPIC_API_KEY="sk-ant-api03-..."
  ```
  **أشهر النماذج:** `anthropic/claude-3-5-sonnet-20241022`, `anthropic/claude-3-5-haiku-20241022`
  </TabItem>

  <TabItem label="OpenAI">
  ```bash
  export OPENAI_API_KEY="sk-proj-..."
  ```
  **أشهر النماذج:** `openai/gpt-4o`, `openai/o1`, `openai/o3-mini`
  </TabItem>

  <TabItem label="Google Gemini">
  ```bash
  export GEMINI_API_KEY="AIzaSy..."
  ```
  **أشهر النماذج:** `google/gemini-2.0-flash`, `google/gemini-1.5-pro`
  </TabItem>

  <TabItem label="DeepSeek">
  ```bash
  export DEEPSEEK_API_KEY="sk-..."
  ```
  **أشهر النماذج:** `deepseek/deepseek-chat`, `deepseek/deepseek-reasoner`
  </TabItem>

  <TabItem label="Ollama (محلي)">
  لتشغيل نماذج مفتوحة المصدر بدون إنترنت أو تكلفة:

  1. تأكد من تشغيل Ollama محلياً (`ollama serve`).
  2. في ملف `opencode.json`:
  ```json
  {
    "model": "ollama/qwen2.5-coder:32b"
  }
  ```
  </TabItem>
</Tabs>

## خدمة OpenCode Zen

يقدم OpenCode خدمة اشتراك واستضافة مدمجة (**OpenCode Zen**) تتيح لك الوصول إلى جميع النماذج المدفوعة الرائدة من فاتورة واحدة دون الحاجة لإدارة مفاتيح API متعددة من شركات مختلفة.
تتوفر هذه الميزة مباشرة داخل خيارات `/connect`.

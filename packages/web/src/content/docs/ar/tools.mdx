يمتلك OpenCode مجموعة من الأدوات البرمجية المدمجة التي تسمح للنموذج بفهم الكود والتفاعل مع بيئة نظام التشغيل لديك بشكل آمن ومنضبط.

---

## الأدوات المدمجة الأساسية

### 1. أدوات الملفات (`fs`)
* **`read_file`**: قراءة محتوى الملفات بالكامل أو في نطاق أسطر محدد.
* **`write_file`**: كتابة ملف جديد أو استبدال ملف كامل.
* **`edit_file`**: إجراء تعديلات موضعية دقيقة على الكتل البرمجية داخل الملفات دون الحاجة لإعادة كتابة الملف بالكامل.
* **`list_directory`**: استعراض محتويات المجلدات وشجرة الملفات.

### 2. أدوات الطرفية والتشغيل (`bash` / `exec`)
* **`execute_command`**: تشغيل الأوامر داخل بيئة الطرفية (مثل تثبيت حزم الاعتماد، تشغيل الاختبارات، أو بناء الحزم).
* يدعم التقاط مخرجات الأوامر (stdout و stderr) وإيقاف العمليات التي تتجاوز مهلة زمنية محددة.

### 3. أدوات البحث والاستكشاف (`search`)
* **`search_files`**: البحث السريع عن النصوص والعبارات النمطية (Regex) داخل كامل مستودع المشروع.
* **`find_by_name`**: العثور على الملفات والمجلدات بناءً على أسمائها أو أنماط الـ Glob.

## مستويات الأمان وسياسات الأذونات (Permissions)

لحماية نظامك من الأوامر الخطيرة أو التعديلات غير المرغوبة، يوفر OpenCode مستويات متعددة للأذونات في ملف `opencode.json`:

```json
{
  "permissions": {
    "bash": "confirm",
    "edit": "allow",
    "read": "allow"
  }
}
```

* **`allow`**: السماح للأداة بالتنفيذ المباشر دون مقاطعة المستخدم.
* **`confirm`**: إيقاف التنفيذ ومطالبة المستخدم بالموافقة الصريحة في الطرفية قبل المتابعة (يوصى بها لأوامر الطرفية `bash`).
* **`deny`**: حظر استخدام الأداة نهائياً.

## الأدوات المخصصة وخوادم MCP

يمكن توسيع قائمة الأدوات لتشمل قواعد بيانات، وخدمات سحابية، وأدوات بحث الويب عبر ربط خوادم **Model Context Protocol (MCP)**.

توفر حزمة **OpenCode SDK** واجهة برمجية كاملة (API) تتيح للمطورين تضمين وكيل OpenCode داخل تطبيقاتهم، أو كتابة سكربتات أتمتة مخصصة بلغة TypeScript أو JavaScript.

---

## التثبيت

```bash
# عبر npm
npm install @opencode/sdk

# أو عبر bun
bun add @opencode/sdk

# أو عبر pnpm
pnpm add @opencode/sdk
```

---

## الاستخدام الأساسي

```typescript
import { OpenCodeClient } from "@opencode/sdk";

// تهيئة العميل
const client = new OpenCodeClient({
  model: "anthropic/claude-3-5-sonnet-20241022",
  apiKey: process.env.ANTHROPIC_API_KEY,
  workspace: "./my-project"
});

async function main() {
  // تشغيل مهمة والحصول على النتيجة
  const result = await client.run({
    prompt: "حلل هيكل قاعدة البيانات في schema.prisma واقترح فهارس (Indexes) مناسبة.",
    agent: "plan" // وضع التخطيط للقراءة فقط
  });

  console.log("استجابة الوكيل:\n", result.output);
}

main().catch(console.error);
```

## تدفق الأحداث (Streaming Events)

يدعم الـ SDK الاستماع المباشر لتدفق المخرجات وتحديثات الأدوات:

```typescript
const session = client.createSession();

session.on("token", (chunk) => {
  process.stdout.write(chunk);
});

session.on("tool:call", (event) => {
  console.log(`[أداة] استدعاء: ${event.tool} بالمدخلات:`, event.args);
});

await session.execute("اكتب اختبار وحدة للدالة calculateTotal");
```

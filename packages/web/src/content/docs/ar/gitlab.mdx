يدعم OpenCode العمل داخل منصة **GitLab** عبر التكامل المباشر مع خطوط أنابيب **GitLab CI/CD**، مما يتيح مراجعة طلبات الدمج (Merge Requests) والتحقق من جودة الكود تلقائياً.

---

## إعداد ملف `.gitlab-ci.yml`

أضف مرحلة عمل لـ OpenCode داخل ملف تكوين CI/CD في مستودعك:

```yaml
stages:
  - review

opencode-review:
  stage: review
  image: node:20
  only:
    - merge_requests
  variables:
    ANTHROPIC_API_KEY: $ANTHROPIC_API_KEY
    GITLAB_TOKEN: $GITLAB_TOKEN
  script:
    - npm install -g opencode-ai
    - opencode -p "افحص التغييرات في هذا الـ Merge Request، وتحقق من عدم وجود ثغرات أمنية واقترح تحسينات الكود."
```

---

## إعداد المتغيرات السرية في GitLab

1. توجه إلى مستودع المشروع في GitLab: **Settings** > **CI/CD**.
2. وسّع قسم **Variables**.
3. أضف المتغيرات التالية:
   * `ANTHROPIC_API_KEY` أو `OPENAI_API_KEY`: مفتاح مزود الذكاء الاصطناعي مع تعيين خاصية **Masked**.
   * `GITLAB_TOKEN`: رمز وصول شخصي أو توكن للمشروع يمتلك صلاحية التعليق وقراءة الـ API.

---

## الاستفادة من التعليقات التلقائية

يمكن لـ OpenCode التعليق مباشرة على الأسطر المعدلة في طلب الدمج (Inline Comments) لتوضيح أي أخطاء أو ملاحظات برمجية دقيقة.

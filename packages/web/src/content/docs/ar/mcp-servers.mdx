title: خوادم MCP (Model Context Protocol)

---

يدعم OpenCode معيار **Model Context Protocol (MCP)** المفتوح، مما يمنحه القدرة على الاتصال بأي خادم MCP خارجي لقراءة البيانات واستدعاء الأدوات، مثل قواعد البيانات (PostgreSQL, SQLite)، وواجهات GitHub، وخدمات السحابة، وغيرها.

---

## تكوين خوادم MCP

يتم تعريف خوادم MCP في ملف إعدادات `opencode.json` داخل قسم `mcp`:

```json
{
  "mcp": {
    "servers": {
      "sqlite": {
        "command": "uvx",
        "args": ["mcp-server-sqlite", "--db-path", "./data/database.sqlite"]
      },
      "filesystem": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-filesystem", "./docs"]
      },
      "fetch": {
        "command": "uvx",
        "args": ["mcp-server-fetch"]
      }
    }
  }
}
```

---

## أنواع الاتصال المدعومة

1. **Stdio (المدخلات والمخرجات القياسية):** وهو النمط الأكثر شيوعاً لتشغيل الخوادم المحلية عبر `npx` أو `uvx` أو ملفات تنفيذية ثنائية.
2. **SSE (Server-Sent Events):** للاتصال بالخوادم البعيدة التي توفر واجهة HTTP عبر تدفق الأحداث:

```json
{
  "mcp": {
    "servers": {
      "remote-service": {
        "url": "https://mcp.internal.company.com/sse",
        "headers": {
          "Authorization": "Bearer YOUR_TOKEN"
        }
      }
    }
  }
}
```

---

## استخدام أدوات MCP

بمجرد تشغيل OpenCode مع خادم MCP نشط، يكتشف الوكيل جميع الأدوات والموارد المتاحة تلقائياً ويستخدمها عند الحاجة أثناء تنفيذ مهامه البرمجية.

للتحقق من حالة خوادم MCP المسجلة، يمكنك استخدام الأمر الفوري:
```text
/help
```
أو مراجعة قسم الأدوات المسجلة في واجهة الـ TUI.

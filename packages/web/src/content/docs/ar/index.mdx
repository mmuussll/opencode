**OpenCode** هو وكيل برمجة ذكي مفتوح المصدر (Open Source) مصمم ليعمل كشريك برمجة زوجي داخل الطرفية (Terminal)، أو كتطبيق لسطح المكتب، أو عبر بيئات التطوير المتكاملة (IDEs).

يتيح لك OpenCode ربط نماذج الذكاء الاصطناعي الرائدة (مثل Claude، GPT، Gemini، DeepSeek بالإضافة للنماذج المحلية عبر Ollama) بملفات مشروعك، وطرفيتك، وأدواتك لتنفيذ المهام البرمجية المعقدة ذاتياً.

---

## المتطلبات الأساسية

قبل البدء في تثبيت OpenCode، تأكد من توفر الآتي:
1. **محاكي طرفية حديث** يدعم الألوان وتنسيقات النص المتقدمة (مثل WezTerm، Ghostty، Alacritty، Kitty، أو Windows Terminal).
2. **مفاتيح API** من مزود الذكاء الاصطناعي الذي تفضله (مثل Anthropic أو OpenAI أو Gemini)، أو إمكانية الاتصال بنماذج محلية عبر Ollama.

## التشغيل لأول مرة

### 1. تشغيل التطبيق
انتقل إلى مجلد مشروعك البرمجي في الطرفية وشغّل الأمر:

```bash
opencode
```

### 2. ربط مزود النموذج (Connect Provider)
بمجرد فتح واجهة المستخدم الطرفية (TUI)، اكتب الأمر الفوري:

```text
/connect
```

سيظهر لك معالج إعداد تفاعلي يتيح لك:
* إدخال مفتاح الـ API الخاص بك مباشرة.
* الاتصال بخدمة OpenCode Zen المدمجة.
* الاتصال بنماذج محلية تعمل عبر Ollama أو vLLM.

## المفاهيم الأساسية

### نظام الوكلاء المزدوج (Dual-Agent Mode)
يدعم OpenCode نمطين رئيسيين للعمل يمكنك التبديل بينهما بضغطة زر `Tab`:

1. **وكيل البناء (Build Agent):** يتمتع بكامل الصلاحيات لقراءة الملفات، وتعديل الكود، وتنفيذ أوامر الطرفية (Bash/Shell) واختبار البرمجيات.
2. **وكيل التخطيط (Plan Agent):** يعمل في وضع القراءة فقط (Read-only)، ويُستخدم لاستكشاف بنية المشروع، وصياغة الخطط، وتحليل الأخطاء دون تعديل الكود مباشرة.

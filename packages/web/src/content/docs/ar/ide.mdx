---

يوفر OpenCode تكاملاً سلساً مع محررات الأكواد وبيئات التطوير المتكاملة (IDEs)، مما يتيح لك الاستفادة من قوة الوكيل الذكي دون مغادرة محرر الكود المفضل لديك.

---

## محررات الأكواد المدعومة

* **Visual Studio Code (VS Code)**
* **Cursor**
* **Windsurf**
* **Zed**

---

## التثبيت داخل VS Code أو Cursor

1. افتح متجر الإضافات (**Extensions Marketplace**) داخل المحرر بالضغط على `Ctrl + Shift + X` (أو `Cmd + Shift + X` على macOS).
2. ابحث عن `OpenCode`.
3. اضغط على **Install**.

---

## سير العمل داخل المحرر

بمجرد تثبيت الإضافة:
1. افتح الطرفية المدمجة داخل المحرر (`Ctrl + \``).
2. شغّل الأمر:
   ```bash
   opencode
   ```
3. سيتصل الوكيل تلقائياً بملفات المشروع المفتوحة في المحرر، ويمكنك استخدام اختصارات الماوس ولوحة المفاتيح لمعاينة التغييرات وقبولها فورياً.

---

## دعم بروتوكول خادم اللغة (LSP Support)

يتفاعل OpenCode مع خوادم الـ Language Server Protocol المدمجة في المحرر للوصول إلى ذكاء الكود:
* الانتقال إلى التعريف البرمجي (`goToDefinition`).
* البحث عن جميع المراجع (`findReferences`).
* استخراج الرموز البرمجية والدوال في نطاق مساحة العمل (`workspaceSymbol`).

يتيح OpenCode للمطورين تخصيص المظهر البصري لواجهة الطرفية (TUI) لتتناسب مع ألوان محاكي الطرفية المفضل لديهم.

---

## السمات المدمجة (Built-in Themes)

يأتي OpenCode مع مجموعة من السمات المجهزة مسبقاً:

* **`default`** / **`dark`**: السمة الداكنة الكلاسيكية المتوافقة مع معظم الطرفيات.
* **`light`**: سمة فاتحة مناسبة للشاشات المضيئة.
* **`nord`**: مستوحاة من لوحة ألوان Nord الهادئة.
* **`dracula`**: ألوان سمة Dracula الشهيرة ذات التباين العالي.
* **`catppuccin`**: لوحة ألوان Catppuccin العصرية (Mocha).

---

## تغيير السمة

يمكنك تعيين السمة المطلوبة في ملف `opencode.json`:

```json
{
  "theme": "nord"
}
```

أو التبديل المباشر أثناء العمل داخل الـ TUI عبر لوحة الأوامر:
```text
/theme
```

---

## إنشاء سمة مخصصة (Custom Theme)

يمكنك تعريف سمة ألوان مخصصة بالكامل بإنشاء ملف باسم السمة داخل مجلد `themes`:

```json
{
  "name": "my-custom-theme",
  "colors": {
    "background": "#1e1e2e",
    "foreground": "#cdd6f4",
    "primary": "#89b4fa",
    "secondary": "#a6e3a1",
    "accent": "#f38ba8",
    "border": "#45475a",
    "error": "#f38ba8",
    "warning": "#f9e2af",
    "success": "#a6e3a1"
  }
}
```

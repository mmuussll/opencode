يتم تكوين وتخصيص سلوك OpenCode عبر ملف `opencode.json`.

---

## أماكن ملف الإعدادات وأولويتها

يبحث OpenCode عن ملف الإعدادات بالترتيب التالي (الإعداد في المستوى الأدنى يتجاوز المستوى الأعلى):

1. **المسار الممرر عبر الطرفية:** `opencode --config <path>`
2. **إعدادات المشروع الحالي:** `./opencode.json` (في جذر المستودع)
3. **الإعدادات العامة للمستخدم:** `~/.config/opencode/opencode.json`

---

## هيكل ملف `opencode.json` الكامل

```json
{
  "$schema": "https://opencode.ai/schema.json",
  "model": "anthropic/claude-3-5-sonnet-20241022",
  "agents": {
    "build": {
      "model": "anthropic/claude-3-5-sonnet-20241022",
      "temperature": 0.2
    },
    "plan": {
      "model": "deepseek/deepseek-chat",
      "temperature": 0.4
    }
  },
  "permissions": {
    "bash": "confirm",
    "edit": "allow",
    "read": "allow"
  },
  "theme": "dark",
  "mcp": {
    "servers": {}
  },
  "env": {
    "NODE_ENV": "development"
  }
}
```

## تفاصيل الخيارات الأساسية

### 1. `model`
النموذج الافتراضي المستخدم للجلسات في حال لم يُحدد نموذج خاص للوكيل.

### 2. `agents`
تخصيص النماذج ودرجة العشوائية (`temperature`) لكل وكيل:
* `build`: إعدادات وكيل التطوير والتعديل المباشر.
* `plan`: إعدادات وكيل الاستكشاف والتخطيط (القراءة فقط).

### 3. `permissions`
إدارة الأمان وصلاحيات تنفيذ الأدوات:
* `"allow"`: تنفيذ مباشر دون سؤال المستخدم.
* `"confirm"`: طلب تأكيد يدوي من المستخدم قبل التنفيذ (موصى به للأوامر الطرفية الحساسة).
* `"deny"`: تعطيل الأداة ومنع استخدامها تماماً.

### 4. `theme`
مظهر واجهة الـ TUI التفاعلية (`"dark"`, `"light"`, أو أسماء السمات المخصصة).

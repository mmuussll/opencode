يتيح نظام الإضافات في OpenCode للمطورين إضافة أدوات مخصصة، والاعتراض على مدخلات ومخرجات الوكيل، والتكامل مع الخدمات الداخلية للشركات.

---

## بنية الإضافة الأساسية

تُكتب إضافات OpenCode بلغة TypeScript أو JavaScript ويتم تصديرها كدالة تستقبل سياق التطبيق:

```typescript
import { definePlugin } from "@opencode/plugin";

export default definePlugin({
  name: "custom-logger-plugin",
  setup(ctx) {
    // خطاف يُستدعى قبل تنفيذ أي أداة
    ctx.on("tool:before", async ({ toolName, args }) => {
      console.log(`[Plugin] جاري تشغيل الأداة: ${toolName}`);
    });

    // إضافة أداة مخصصة جديدة
    ctx.registerTool({
      name: "notify_slack",
      description: "إرسال إشعار إلى قناة Slack الخاصة بفريق التطوير",
      parameters: {
        type: "object",
        properties: {
          message: { type: "string" }
        },
        required: ["message"]
      },
      async execute({ message }) {
        // منطق الإرسال إلى Slack...
        return { status: "success", delivered: true };
      }
    });
  }
});
```

## تسجيل الإضافات في المشروع

لتفعيل إضافة في مشروعك، أضف مسارها أو اسم حزمتها في ملف `opencode.json`:

```json
{
  "plugins": [
    "./plugins/custom-logger.ts",
    "@company/opencode-auth-plugin"
  ]
}
```

## خطافات دورة الحياة المتاحة (Lifecycle Hooks)

* **`session:start`**: عند بدء محادثة أو جلسة جديدة.
* **`session:end`**: عند إنهاء الجلسة أو مسحها عبر `/clear`.
* **`prompt:transform`**: تعديل أو إضافة سياق إلى رسالة المستخدم قبل إرسالها للنموذج.
* **`tool:before`**: فحص أو تسجيل أو إيقاف تنفيذ الأداة قبل بدئها.
* **`tool:after`**: معالجة أو فلترة نتيجة تنفيذ الأداة قبل إرجاعها إلى النموذج.
